# 🖥️ Capturas de Pantalla de MicroPro / microbrn (Software Oficial de Windows)

Este directorio contiene las capturas de pantalla de referencia del software original para Windows **MicroPro (`microbrn.exe`)**, desarrollado por Kitsrus / DIY Electronics para la familia de programadores PIC **K128, K149 y K150**.

---

## 🎯 Propósito y Utilidad para el Proyecto
Estas pantallas sirven como especificación visual y funcional de referencia para:
1. **Comportamiento del Protocolo P18A/P018:** Contrastar cómo la herramienta oficial interactúa con el firmware del programador.
2. **Opciones de Calibración:** Inspeccionar el manejo de palabras de calibración de oscilador interno (**OSCCAL**) en PICs de gama básica/media y la calibración especial de la familia **PIC10F** (con respaldo / backup).
3. **Fusibles y Configuración:** Cómo organiza los registros de configuración, IDs de usuario y bits de protección de código.
4. **Organización de UI:** Servir de guía para las mejoras ergonómicas en la app Android `PIC-k150-Programing` (programación selectiva de ROM/EEPROM/Fuses, visualización de memoria y diagnóstico del programador).
